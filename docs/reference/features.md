# Features and permissions

## Configuration

| Feature                                                      | Role            |
| ------------------------------------------------------------ | --------------- |
| Define and maintain products, tests, and their configuration | Quality Manager |

## Intake

| Feature                                                          | Role            |
| ---------------------------------------------------------------- | --------------- |
| Register a sample with a serial number and product               | Technician      |
| Find a sample and view its product, status, and configured tests | Technician      |
| Complete a sample                                                | Technician      |
| Reopen or archive a completed sample                             | Quality Manager |
| Submit test results                                              | Technician      |
| Void a sample                                                    | Quality Manager |

Role descriptions are in [Roles](roles.md).

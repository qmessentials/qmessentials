# QMEssentials web application

The browser application is built with React, TypeScript, Vite, TanStack Router,
TanStack Query, Tailwind CSS, and Base UI.

## Run locally

From this directory:

```sh
npm install
npm run dev
```

The development environment is configured through `.env.development`. For the
complete system setup, see [Run QMEssentials locally](../../docs/how-to/run-locally.md).

## Verify changes

```sh
npm run lint
npm run build
```

`src/routeTree.gen.ts` is generated by TanStack Router. Make route changes in
`src/routes` rather than editing the generated tree by hand.
